# Combat Matrix — Minimum Tests Before Lock

Run these as **cheap static images** (or very short clips) before any expensive film generation.

## Character passport

| Test | Purpose |
|------|--------|
| Front, three-quarter, profile, back | Identity holds from all sides |
| Wide / medium / close | Scale and detail consistency |
| Low angle + high angle | No age or face drift under perspective |
| Scene lighting A (from location passport) | Looks correct under real key light |
| Scene lighting B (second location if used) | Same |
| Two-shot with every co-star | Both identities survive sharing the frame |
| Variant states (`_wet`, `_blood`, etc.) | Each variant is its own passport and must pass its own matrix |

Score each cell pass/fail. Require full pass for lock.

## Location passport

| Test | Purpose |
|------|--------|
| Establishing wide | Geometry and palette |
| Medium interior / key positions | Relative distances hold |
| With lead character in frame | Character + location together |
| Alternate time-of-day if claimed | Only if the passport supports it |

## Prop (hero props only)

| Test | Purpose |
|------|--------|
| In hand (close) | Detail and scale |
| On surface, different distances | Consistency |
| Under scene lighting | Material response |

## Scoring rule

10/10 identity + wardrobe + geometry.  
No "close enough". If it fails, revise the descriptor or sheet and re-test. Never lock a partial pass.
