# 15 Blocks — Expanded Guidance

## 1. Character count lock
Always open with an explicit integer count. Models invent people the moment the count is soft.

Good: `EXACT 2 CHARACTERS — NO DUPLICATES. Only the man @cal and the woman @mira are present.`

## 2. Character passports
Paste the full `descriptor.md` content for each required tag. Do not summarise. Do not "clean up".

## 3. Location + spatial map
Include full location descriptor, relative positions of key elements (door is 2.5 m left of window), and explicit 180° line.

## 4. Props
Only locked props. Treat hero props with the same respect as characters.

## 5. Time of day & light
Light direction, quality, colour temperature, practical sources. Never "well lit". Always shaped by the location passport.

## 6. Camera
One lens. One primary move. Shot size and angle stated clearly. FOV changes only across a cut.

## 7. Action & timed beats
Break continuous action into short observable beats. For long one-shots use 0–6 / 6–14 / 14–24 / 24–30.

## 8. Dialogue & performance
Verbatim lines + emotional / physical intention. Lip-sync notes if the model generates audio.

## 9. Physics & continuity
State that must persist: injuries, wetness, displaced objects, blood, broken glass.

## 10. Style & grade
60:30:10 colour share. Any locked paragraph from the visual bible.

## 11. Motion grammar
Camera move must be motivated by an event inside the clip. Explicitly reject "frozen people while camera moves".

## 12. Reference roles
Every reference file gets two sentences: what it owns, what it is forbidden to influence.

## 13. Sound / ambience
Only if the chosen model supports native audio generation in the same pass.

## 14. Technical
Duration, aspect ratio, resolution, seed if controlled, model-specific switches.

## 15. Positive frame statement
Close by restating presence and absence in positive language.
