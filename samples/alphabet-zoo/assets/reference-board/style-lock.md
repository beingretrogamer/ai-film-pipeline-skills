# Style Lock — Alphabet Zoo

**Art direction:** Bright Pixar / modern preschool 3D. Soft shapes, saturated but friendly colors, clean surfaces, gentle subsurface scattering on characters.

**World:** Sunny Alphabet Zoo. Rolling soft green hills, colorful animal houses shaped like big friendly letters, clear blue sky with a few soft clouds, warm golden morning light. Musical notes sometimes float as soft particles during the chant.

**Camera language:** Simple and readable. Gentle push-ins, soft orbits, low angles for cuteness. No shaky cam, no extreme wide-angle distortion, no rapid cuts inside a single generation.

**Color grade:** Warm, high-key, slightly creamy highlights. Never cold, never desaturated, never high-contrast noir.

**Audio character:** Clear children’s chant, light percussion or claps, soft animal accent sounds. Native audio from the video model is preferred when available.
